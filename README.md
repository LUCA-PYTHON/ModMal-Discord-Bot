# ModMal-Discord-Bot
Dieses Projekt stammt aus dem Jahr 2022/2023. Es ist ein ModMal Bot für Discord, dieser kann noch viele weiteren Funktionen. Er ist mit einer MYSQL Datenbank verbunden und sehr aufwendig gestalltet.

Um den Bot starten zu können nutze ich aktuell discord.py Version 2.1.0 und eine MYSQL Datenbank. Dazu nutze ich aktuell Pycharm aber eine Version aus dem Jahr 2022.
